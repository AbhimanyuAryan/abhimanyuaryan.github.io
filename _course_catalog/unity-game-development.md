This course covers Unity3D game development with a hands-on, project-based approach. Starting from the Unity editor itself, we progressively build up to real game mechanics — particle systems, physics, AI pathfinding, and complete mini-games.

All lectures are taught in **Hindi** and are suitable for beginners with basic programming knowledge.

Inspired by:

- [How to Build an Agent](https://ampcode.com/notes/how-to-build-an-agent) (Amp, Go, ~300 lines)
- [The Emperor Has No Clothes](https://www.mihaileric.com/The-Emperor-Has-No-Clothes/) (Mihail Eric, Python, ~200 lines)

**Reference implementation:** [pi-mono](https://github.com/badlogic/pi-mono) &nbsp;·&nbsp; **Provider:** Anthropic Claude (`anthropic-messages` API) &nbsp;·&nbsp; **Language:** TypeScript / Node.js

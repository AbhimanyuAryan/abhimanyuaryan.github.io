Unity Game Development

Learn Unity3D from scratch — particle systems, game physics, AI, and building complete games. Taught in Hindi with English subtitles.

Beginner Hindi 5 lessons

unity   game-dev   c-sharp   particle-systems

This course covers Unity3D game development with a hands-on, project-based approach. Starting from the Unity editor itself, we progressively build up to real game mechanics — particle systems, physics, AI pathfinding, and complete mini-games.

All lectures are taught in Hindi and are suitable for beginners with basic programming knowledge.

Lessons

#1
Particle System 1: Modules

An introduction to Unity's Particle System and its module-based architecture. Learn how the particle system is structured and how modules control every aspect of particle behaviour.

#2
Particle System 2: Emission & Shape Module

Deep dive into the Emission and Shape modules — controlling how many particles are spawned per second and the 3D shape they emit from.

#3
Particle System 3: Velocity Modules

Control how particles move over their lifetime using Velocity over Lifetime, Limit Velocity, and Inherit Velocity modules.

#4
Particle System 4: Force Control Modules

Apply physics forces to particles using the Force over Lifetime module and Unity's Particle System Force Fields.

#5
Particle System 5: Importing Particle System Packages

Learn how to import, customize, and use pre-built Unity Particle System packages from the Asset Store and Unity's own sample packs.
